# Life CFO — Trust Model

Last updated: 2026-07-12

## Trust posture
Life CFO must feel like a glass box, not a black box.

Users should be able to understand:
- what the system can see
- what it cannot see
- what it is doing
- what it is not doing
- why a conclusion was reached
- what would change that conclusion

Trust is earned through legibility, not mystery.

## Core trust commitments
Life CFO is built around these commitments:

### 1. User control
The user remains in control.

Life CFO may analyse, explain, compare, and summarise.

It does not act on behalf of the user.

### 2. Bounded behavior
Life CFO reasons within the bounds of:
- available household data
- current product capabilities
- the user's actual question or workflow

It should not behave as though it has broader awareness than it does.

### 3. Calm communication
Life CFO should communicate in a way that avoids unnecessary alerts, pressure, or ambiguity.

It should avoid:
- urgency by default
- alarmist framing
- opaque AI language
- unnecessary complexity
- unclear consent

### 4. Explainability
Life CFO should be able to clarify:
- what data it used
- what assumptions it made
- what uncertainty remains
- what could change the answer

### 5. No hidden autonomy
Life CFO does not:
- move funds
- schedule payments
- change core user data silently
- auto-commit decisions
- perform autonomous financial actions

### 6. Household boundary
The household is the main access boundary across the system.

This means financial data is treated as household-scoped, not as a loose collection of individual records.

## Product trust test
A feature should be rejected or redesigned if it:
- increases cognitive load
- hides important boundaries
- makes the system feel manipulative
- creates pressure to engage
- makes users feel watched
- implies autonomous action when none exists

## Desired product qualities
The product should be:
- legible
- non-pressuring
- easy to disengage from
- clear about what Life CFO can currently see
- clear that nothing moves automatically
